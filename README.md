# عالم الحموض والقواعد – رحلة تفاعلية في الكيمياء

منصة تعليمية عربية تجريبية مبنية باستخدام React وTypeScript وVite.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## الاختبارات والبناء

```bash
npm test
npm run build
```

## المكونات المتاحة في النسخة الأولى
- واجهة عربية متجاوبة مع وضع ليلي ونهاري.
- ثمانية دروس بمراحل التعلم الخماسي.
- مختبر مطوّر لقياس الرقم الهيدروجيني والتعادل والمعايرة، وعروض أولية للكواشف والتأين والأمطار الحمضية.
- اختبار تفاعلي قصير، وألعاب أولية، ولوحة تقدم محلية.
- سير عمل GitHub Pages.

## القيود الحالية
- حسابات المحاكاة مخصصة لحمض وقاعدة قويين أحاديي التكافؤ عند 25°م وبافتراض سلوك مثالي؛ لا تستخدم للمحاليل الضعيفة أو عالية التركيز دون نموذج مناسب.
- المحاكاة الجسيمية والأمطار الحمضية حالياً عروض تعليمية مبسطة وليست نماذج علمية كاملة.
- الألعاب الست تحتاج إلى تطوير مستقل؛ بنك 100 سؤال والفيديوهات والنماذج ثلاثية الأبعاد والشهادة النهائية لم تُنجز بعد.
- لا يُعد وجود إعدادات النشر دليلاً على نجاح البناء أو النشر؛ راجع سجل Actions.
- تفعيل Pages من Settings → Pages → Source: GitHub Actions.

## خطة التطوير
1. مراجعة البناء والاختبارات وإصلاح أي أخطاء.
2. تطوير محاكاة المعايرة والأحماض الضعيفة مع تحقق علمي.
3. استكمال الألعاب وبنك الأسئلة والأنشطة المتدرجة.
4. إضافة النماذج ثلاثية الأبعاد والوسائط الموثوقة وموارد المعلم والشهادات.

## الواجهة العلمية
- صورة مختبر أصلية مولّدة للمشروع محفوظة في `src/assets/chemistry-lab.webp`، ومضغوطة بصيغة WebP.
- يستورد Vite الصورة مباشرة ويولّد رابطها وفق المسار `/Chemistry/` لضمان تحميلها على GitHub Pages.
- الواجهة متجاوبة، وتدعم تقليل الحركة، وتتضمن تسمية واضحة لحقل اسم الطالب الاختياري.
- بقيت الدروس والتجارب والألعاب والاختبارات المتاحة كما هي.


## المختبر المطوّر: المرحلة الأولى

ثلاث تجارب مكتملة متاحة من تبويب «المختبر»:

1. **قياس الرقم الهيدروجيني:** اختيار HCl أو NaOH أو الماء، وضبط التركيز والحجم، وإدخال المسبار بالنقر على الجهاز أو الزر. لا تظهر قراءة قبل التنفيذ.
2. **التعادل:** اختيار HCl أو HNO₃ مع NaOH أو KOH، وضبط التركيز والحجم، وخلط المحلولين، وقياس الناتج. تعرض النتائج المولات الابتدائية والمستهلكة والفائضة والحجم الكلي والمعادلة الخاصة بالمواد المختارة.
3. **المعايرة:** سحاحة 50 مل بصمام قابل للنقر أو التشغيل بلوحة المفاتيح. القطرة 0.05 مل، مع إضافة سريعة 1 مل. يسجل المسبار القراءات الفعلية في جدول ونقاط منفصلة عن المنحنى الحسابي، مع علامة التكافؤ. يُرفض إعداد لا يسمح بعبور التكافؤ ضمن السحاحة.

الأدوات مرسومة بـSVG مع زجاج شفاف وسوائل وحركة خفيفة، وتعمل بالنقر ولوحة المفاتيح دون مكتبة ثلاثية الأبعاد ثقيلة. الأحجام البصرية توضيحية؛ القيم العددية هي مرجع القياس. الصوت اختياري ومكتوم افتراضياً. لا توجد فقاعات غاز ناتجة من تعادل هذه المواد، والألوان بحسب pH خيار توضيحي موسوم، وليست ألوان المحاليل الحقيقية.

كل تجربة تتضمن هدفاً وأدوات وخطوات وسلامة وفرضية وملاحظات واستنتاجاً وتقويماً بتغذية راجعة. لإتمامها يُشترط تنفيذ القياس والإجابة الصحيحة وتعبئة النصوص؛ المعايرة تشترط أيضاً تسجيل قراءات وعبور التكافؤ. لا يجري تصحيح النص الحر آلياً.

يحفظ المتصفح المسودات وآخر تقرير لكل تجربة، بما فيه قراءات المعايرة، ضمن `chemistry-laboratory-v1`. يمكن استعادة التقرير وطباعته باسم الطالب المدخل في الرئيسية. تمنح كل تجربة مختلفة 30 نقطة مختبر وشارة واحدة، وتظهر في المختبر ولوحة الطالب؛ نقاط المختبر مستقلة عن نقاط الألعاب. زر إعادة التجربة يمسح المحاولة الحالية ويحافظ على سجل الإنجاز. التخزين محلي لهذا المتصفح فقط، ويظهر تنبيه إذا تعذر الحفظ.

### النموذج العلمي

الملف `src/labScience.ts` يستخدم حفظ الشحنة واتزان الماء: عند 25°م، Kᵥ = 10⁻¹⁴، وفرق التركيز الستوكيومتري d = (n الحمض − n القاعدة) / الحجم الكلي. يُحل h − Kᵥ/h = d ثم pH = −log₁₀(h)، بصيغة مستقرة عددياً. لا يُستبدل الحساب بقيمة 7 ضمن عتبة تخفيف اصطناعية، ولا يُحصر pH قسرياً بين 0 و14.

الافتراضات: تأين كلي لمواد قوية أحادية التكافؤ، محاليل مثالية وأحجام مضافة ودرجة حرارة ثابتة. تُهمل معاملات النشاط والحرارة المتولدة وامتصاص CO₂ وأخطاء الجهاز. المجال التعليمي للتركيز 10⁻⁹–1 مول/لتر وللحجم 1–250 مل؛ عند أطراف المجال قد تختلف القياسات الواقعية عن النموذج المثالي. **لم تُضف محاليل ضعيفة**؛ تحتاج إلى نموذج اتزان مستقل وثوابت تأين، ولا تُعامل بمعادلات القوية.

### ما بقي للمرحلة التالية

- الكواشف: العرض القديم يوضح ألواناً تقريبية فقط، ولا يقدم تجربة قطارات مكتملة أو اتزاناً للكواشف.
- القوة والتأين: العرض القديم رمزي، ولا يحسب اتزان أو نسب تأين المحاليل الضعيفة.
- الأمطار الحمضية: معلومات توضيحية، دون نموذج كمي للنبات أو التربة أو المياه.

وسمت هذه الأقسام داخل الواجهة بأنها «عرض أولي»، ولا تمنح نقاطاً أو شارات. لم تُحذف الدروس الثمانية أو الألعاب أو الاختبارات أو الصورة الرئيسية أو اسم المعلمة.

### التحقق

- `npm test`: 16 اختباراً لحسابات الحمض والقاعدة، والتكافؤ، وحفظ المولات والحجم، وتأين الماء والتخفيف الشديد، واتزان الشحنة، ورتابة منحنى المعايرة، ورفض المدخلات غير الصالحة.
- `npm run build`: تحقق TypeScript وبناء Vite مع المسار `/Chemistry/`.
- فُحصت التجارب في Chromium على 1440×1000 و390×844: القياس، المدخلات الفارغة، التعادل وفائض القاعدة، القطرات والتكافؤ، الحفظ والاستعادة بعد إعادة التحميل، عدم تكرار النقاط، إعادة التجربة، الطباعة باسم الطالب، تقليل الحركة، بقاء المحتوى القديم، وعدم وجود أخطاء تشغيل أو تجاوز أفقي.
